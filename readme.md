# Cisco Cheatsheet

## Description
A static web-based Cisco IOS cheat sheet for network students and engineers. It includes command references for switch/router configuration, monitoring, inter-VLAN routing, static routing, backup, and route table interpretation.

## Files
- `index.html` — page markup
- `style.css` — styles and theme
- `script.js` — interactivity
- `readme.md` — project documentation

## Usage
1. Open `index.html` in a web browser.
2. Use the search bar to filter commands.
3. Click a copy icon to copy any command.
4. Toggle theme using the top-right button.
5. Navigate between sections using the top menu.

## Features
- Search and highlight
- Copy commands to clipboard
- Dark/light theme
- Sticky nav with section highlighting
- Responsive design
